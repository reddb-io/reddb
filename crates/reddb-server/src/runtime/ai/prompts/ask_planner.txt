Rules:

- Use `reddb_catalog`, `reddb_describe_collection`, and `reddb_find_field` only when the narrowed schema is insufficient.
- Use `reddb_query` only for a bounded exploratory read. Exploration is evidence for planning, not the answer.

- Derive collection and field names only from the narrowed schema or authorized tool results. Never invent identifiers.
- When only one step remains, call `reddb_final_query` immediately.
